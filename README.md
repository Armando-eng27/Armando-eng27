### 👨‍💻 Sobre Mí
Soy Ingeniero de Sistemas con experiencia en infraestructura de TI, administración de redes y desarrollo de aplicaciones web y de escritorio a la medida. Me enfoco en construir sistemas robustos, seguros y eficientes orientados a la automatización de procesos empresariales y la gestión comercial.

* **Lenguajes y Backend:** Python, PHP, Flask, JavaScript, SQLite, MySQL, SQLAlchemy.
* **Frontend y Estilos:** HTML5, CSS3, JavaScript, Bootstrap.
* **Herramientas y Automatización:** Git, GitHub, PyCharm, ngrok, OpenPyXL, PyMuPDF.

### 🚀 Soluciones y Sistemas de Gestión (Comerciales)
> *Nota: Estos sistemas forman parte de nuestro catálogo de soluciones especializadas para negocios bajo la marca **Solvix**. Para proteger la propiedad intelectual, los códigos fuente se mantienen en repositorios privados.*

* 🎨 **SistemaTatuajes:** Aplicación web integral para la gestión de citas, control operativo y seguimiento de clientes en estudios de tatuaje.
* 📚 **E-Learning Platform:** Plataforma educativa interactiva desarrollada con Flask y MySQL, con gestión de roles, filtros por áreas y generación de certificados en PDF.
* 🎫 **Sistema de Tickets (Help Desk):** Solución robusta para el seguimiento de incidencias, soporte técnico automatizado y control de reportes.
* 💇‍♀️ **Sistema Estética:** Software especializado en control de agendas, servicios, caja y administración para centros de belleza y salones.
* 🍦 **Paletería POS:** Sistema de punto de venta optimizado para control de inventarios, gestión de caja y ventas en negocios de heladería y paletería.
